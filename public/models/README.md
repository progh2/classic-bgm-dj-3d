# 집사 모델 출처와 이용 조건

| 파일 | 역할 | 원본 |
|---|---|---|
| `sebastian.vrm` | 집사 세바스티안 | VRoid Studio 샘플 모델 「桜田 史利矢 (Sakurada Fumiriya)」 |

- 제작: VRoid プロジェクト (pixiv Inc.)
- 배포처: [OpenGameArt — VRoid Studio CC0 models](https://opengameart.org/content/vroid-studio-cc0-models)
- 원 출처 안내: [VRoid 공식 FAQ — 샘플 모델의 이용 조건](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use)

## 파일에 담긴 이용 허가 (VRM 0.x meta)

`otherLicenseUrl` 에 명시된 조건:

```
allowed_to_use_user      = everyone
corporate_commercial_use = allow
personal_commercial_use  = profit
modification             = allow
redistribution           = allow
credit                   = unnecessary
```

재배포·수정·상업적 이용이 모두 허용되며 크레딧 표기는 의무가 아닙니다.
의무는 아니지만 출처 안내서(단계 3)에 표시합니다.

## 이 저장소에서 가한 수정

파일 이름만 `fumiriya.vrm` → `sebastian.vrm` 로 바꿨습니다. 모델 자체는 그대로입니다.
같은 파일을 [yutnori](https://github.com/progh2/yutnori) 저장소에서도 쓰고 있으며,
그쪽에서 웹 로딩을 위해 텍스처를 1024px·JPEG q88 로 재인코딩한 판본입니다
(지오메트리·본·블렌드셰이프는 원본 그대로).

## 임시 배역

정장 차림의 전용 집사 모델을 마련하기 전까지 쓰는 임시 모델입니다.
교체할 때는 이 문서의 출처·조건을 새 모델 기준으로 다시 씁니다.
