크기는 1.54 × 0.95 × 0.59 m (가로 × 높이 × 세로), 합계 약 740KB.

```
classic-console/

  ClassicConsole_01.bin           222KB   (지오메트리 — 해상도와 무관하게 공통)

  textures/…_arm_1k.jpg           157KB   AO / 거칠기 / 메탈
```

질감이 부족하면 2k 로 올리는 것을 검토합니다(2k 는 약 2MB).
